# 🌐 Portfolio Website

A **personal portfolio website** designed and developed by **Monish M M** to showcase projects, skills, experience, and achievements in a visually appealing and responsive manner.  

---

## 🚀 Features

- 🎨 **Modern and Responsive Design** – Works seamlessly on desktop, tablet, and mobile.  
- 💼 **Projects Section** – Displays personal and professional projects with live links.  
- 🧠 **Skills Overview** – Highlights technical and creative skills.  
- 📄 **Resume Section** – Includes downloadable resume in an elegant layout.  
- 📸 **Gallery Section** – Showcases photography and design works.  
- 📬 **Contact Form** – Allows visitors to reach out directly via email.  

---

## 🛠️ Built With

- **HTML5** – Structure  
- **CSS3 / Bootstrap** – Styling and responsiveness  
- **JavaScript** – Interactivity and animations  
- **Font Awesome** – Icons and social links
